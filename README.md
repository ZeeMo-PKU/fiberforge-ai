# 纤程智控 Demo

“纤程智控——面向PAN基碳纤维制备的可解释AI工艺推荐系统”显微形貌证据判读原型。

在线演示：https://zeemo-pku.github.io/pan-fiber-ai-evidence-demo/

## 功能

- 展示5组PAN初生纤维显微图样例；
- 点击样例后显示结晶度、晶粒尺寸、形貌判读、工艺解释和建议动作；
- 单页静态实现，不需要API Key或后端服务。

## 证据边界

原型中的图像和数值来自同一篇同行评审论文的同一实验体系，演示结论仅用于说明证据化判读与可追溯推荐流程，不外推为生产线通用最优参数。

数据与图像来源：杨振华，党延金，巨安奇. 干喷湿纺碳纤维原丝制备过程中凝固浴条件对初生纤维结构的影响[J]. 塑料科技，2026，54(2)：134-138. DOI: 10.15925/j.cnki.issn1005-3360.2026.02.024。

下载 `index.html` 后可直接双击打开，无需安装环境。
