# 纤程智控

本仓库是挑战杯项目“纤程智控——面向 PAN 基碳纤维制备的可解释 AI 工艺推荐系统”的网页演示原型。项目聚焦 PAN 基碳纤维制备过程中的显微形貌证据判读，尝试将实验图像、结构参数、工艺解释和调整建议串联为可追溯的分析链路。

在线演示：https://zeemo-pku.github.io/xianchengzhikong/

## 项目背景

PAN 基碳纤维制备涉及多个相互耦合的工艺参数。显微图像能够反映初生纤维的结构与形貌差异，但从图像证据到工艺决策之间仍需要清晰、可解释的推理过程。本原型用于展示项目的核心思路：不只给出推荐结果，还同时呈现结果所依据的图像、数值与工艺解释。

## 演示内容

- 展示 5 组 PAN 初生纤维显微图样例。
- 对每组样例展示结晶度、晶粒尺寸和形貌特征。
- 给出与图像证据对应的工艺解释和建议动作。
- 以交互页面演示“证据—判读—解释—建议”的可追溯流程。

## 技术形式

演示页采用单页静态实现，不需要 API Key、数据库或后端服务，适合用于挑战杯项目展示、方案讲解和原型验证。

## 证据边界

原型中的图像和数值来自同一篇同行评审论文的同一实验体系。当前页面是挑战杯项目的概念演示原型，用于说明证据化判读与可追溯推荐流程，不代表已完成生产线部署或泛化验证，也不应将演示结论外推为通用最优工艺参数。

数据与图像来源：杨振华，党延金，巨安奇. 干喷湿纺碳纤维原丝制备过程中凝固浴条件对初生纤维结构的影响[J]. 塑料科技，2026，54(2)：134-138. DOI: 10.15925/j.cnki.issn1005-3360.2026.02.024。
